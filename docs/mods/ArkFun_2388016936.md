## Назначение и функции

ArkFun добавляет предметы для строительства и обороны базы.

| Функция/содержимое | Цель | Основные ассеты |
| --- | --- | --- |
| Полы, блок-полы, стены и потолки | Расширить набор строительных частей; для частей пола есть цветовые материалы | `PrimalItemStructure_Floor_AF`, `PrimalItemStructure_Floor_Block_AF`, `PrimalItemStructure_Wall_AF`, `PrimalItemStructure_Ceiling_AF` и соответствующие BP/mesh/material |
| Heavy и Tek автоматические турели | Дополнительные варианты автоматической защиты базы | `BP_AutoTurret_Heavy_AF`, `AF_AutoTurretTek`, предметы/engram entries, `ProjTekTurret_AF`, `S_TurretConfig` |
| Cryofridge и Training Dummy ресурсы | Включённые в пакет ассеты/ресурсы этих игровых объектов | `MIC_CryofridgeDeactivated`, `training_dummy` и материалы/текстуры из `PrimalEarth` |

Это описание отражает состав локального пакета. По одним ассетам нельзя подтвердить, какие из включённых базовых ресурсов меняют игровое поведение по сравнению с оригинальными объектами.

## Турели: баланс и автоматизация

Да, в моде есть две автоматически наводящиеся турели. Они используют стандартный turret targeting/настройки S+, расходуют боеприпасы и требуют электричество. У обеих включены lock/pin и командное ограничение активации. В проверенных блюпринтах нет отдельного скрипта, который сам строит турели, создаёт боеприпасы или позволяет клиенту менять их характеристики через `NetServer` RPC.

Параметры оружия задаёт серверный `ArkFun_BP` из секции `[ArkFun]`. При отсутствии положительного override он подставляет следующие рабочие значения:

| Параметр | AF Heavy Auto Turret | AF Tek Turret |
| --- | ---: | ---: |
| FireDamageAmount | 345 | 70 |
| FireInterval | 0,35 с | 0,35 с |
| NumBulletsPerShot | 2 | 2 |
| InventorySlots | 100 | 100 |
| Боеприпас | Advanced Rifle Bullet | Element Shard |
| Здоровье CDO турели | 20 000 | 4 500 |

Tek-турель дополнительно использует настраиваемый снаряд:

| Параметр снаряда | Значение по умолчанию |
| --- | ---: |
| DirectDamage | 750 |
| ExplosionDamage | 600 |
| ExplosionRadius | 150 UU (1,5 м) |
| BulletSpeed / MaxSpeed | 7 500 UU/с |
| ProjectileLife | 4,2 с |

Снаряд помечен `bIgnoreDirectImpactRadialDamage=true`; итоговый урон при прямом попадании и взрыве зависит от правил урона ARK и не был измерен в игре. Тем не менее сочетание двух снарядов за выстрел, 750 direct и 600 explosion — заметный потенциальный дисбаланс относительно обычной защиты. Это не доказывает, что каждый выстрел складывает все значения в одну цифру.

`ArkFun_BP` принимает положительные значения без видимого верхнего клампа для `Damage`, `FireInterval`, `BulletsPerShot`, `InventorySlots`, `BulletSpeed`, `DirectDamage`, `ExpDamage` и `ExpRadius`. Оператор сервера может намеренно настроить практически неограниченную автоматическую оборону. Эти параметры читаются из серверного Game.ini; в проверенных ассетах не найден клиентский RPC для их изменения. Поэтому это **серверно-настраиваемый риск баланса**, а не подтверждённый способ игроку удалённо усилить турели.

Обе турели наследуют проверки допустимого размещения через `SP_IsTurretAllowedToBuild` / `SP_IsTurretAllowedToBuildEx`; отдельного обхода правил установки в их Blueprint-графах не найдено. Реализация этих внешних S+ helper-функций отдельно не проверялась. Engram-entries требуют соответствующий обычный Heavy/Tek Turret engram как prerequisite, так что явного обхода технологического unlock в этих двух entry не видно.
