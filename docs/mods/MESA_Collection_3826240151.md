## Как устроен стек

- **Ядро — MESA (`MesaMod2`).** Почти вся логика серверов в одном моде: служебные CCA-акторы, баф игрока с ~20 RPC, переопределения `BPServerHandleNetExecCommand`, около 300 ini-ключей (`[OfficalMesaModSettings]` и ключи через обёртку). 100x-сборка монтируется в тот же путь и подменяет ядро.
- **Сателлиты.** OSD/VEIN (`MesaMod3`), Skins, 100x-оружие, ивенты — отдельные моды, связаны с ядром кейбиндами (F7, F3, Alt+K) и общими предметами (Dino Core, Tek Bola, перки, ключ-карты).
- **Карты.** Своя карта Mesa City (тип 2) и расширения (тип 4), которые подменяют ванильные подуровни одноимёнными файлами. Логики в расширениях почти нет: тома запрета дино и полётов, урон в пещерах, терминалы.
- **Клиенты серверных плагинов (ArkApi).** WShopUI, MAGA ORP, Getter Component (HWIDBans), Items+ Companion, ARK Guardian. Пустые серверные обработчики в BP перехватывает плагин; данные идут через синглтон и RPC.
- **Дубли.** Логика Better Horde Mode встроена в OSD/VEIN (свои копии `BP_HordeEventOverride` и `Buff_HordeDinos`, те же ini-ключи), а сам BHM тоже в коллекции. C+ — замена S+ по тому же пути `/Game/Mods/StructuresPlusMod`.

## Кандидаты для security-разбора

Прочитаны по байткоду, вживую не проверялись. Подробности — в карточках.

| Мод | Место | Суть |
| --- | --- | --- |
| Awesome SpyGlass | `Request Inventory Items(Actor, Limit)` | Сервер отдаёт содержимое инвентаря любого присланного актора: без дистанции, команды и флага `AllowItemList` |
| Awesome SpyGlass | `Set Server Settings(Settings)` | Глобальные настройки пишутся в save и рассылаются всем без админ-проверки на сервере |
| Pickup Gun | `ROS_AntiDupeWeaponDrop(Inv, ItemID)` | `RemoveItem` из инвентаря, который прислал клиент, без проверки владельца |
| MESA | `AddGolemBuff`, `ROS TryGiveSaddle`, `Msa Execute Pull*`, `BP_Propagator_Msa` | `mod_audit` D1/D2/D5: баф на чужого дино, не проверенный `RemoveItem`, недоверенный `ObjParam` до `AddItemObjectEx` |
| MESA | `ROS_TEst`, `ROS_UnlockEngrams`, `ROS_LevelUpDino` | Отладочные и мощные RPC — проверить гейты |
