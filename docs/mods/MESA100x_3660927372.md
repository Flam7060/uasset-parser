Три предмета для 100x-серверов MESA:

| Предмет | Что это | Где крафтится |

| Grappling Hook (`PrimalItem_WeaponCrossbow_Child_MESA100x`) | Арбалет-грапплинг: трос до 7000 (`ProjGrapHook_MESA100x.MaximumRopeDistance`); `bDontTakeAmmoOnReload=true` — крюки при перезарядке не тратятся | Tek Replicator, Anvil Bench, S+ Replicator, S+ Smithy |
| Gravity Grenade Launcher (`…TekGrenadeLauncher_Child_MESA100x`) | Наследник Tek Grenade Launcher: 3 слота, заряженные Tek Gravity Grenade (Extinction), `AmmoPerClip=3` | Tek Replicator, S+ Replicator |
| 100x Tek Grenade Launcher (`…TekGrenadeLauncher_Child_100xGLaunch`) | Подменяет ванильный Tek Grenade Launcher (`Remap_Items`); в `InitialProjectileTypeSlots` 6 слотов Tek Grenade | Как ванильный (через ремап) |

## Как сделано

- Только данные, без собственной логики. `PrimalGameData_MESA100x` задаёт три `AdditionalEngramBlueprintClasses`, один `Remap_Items` (ванильный Tek GL → 100x-наследник) и `AdditionalStructureEngrams` для станций (ваниль и S+/C+).
- У гранатомётов свои копии хелпер-бафа (`Buff_TekGrenadeLauncherHelper_*`): HUD слотов, колесо выбора боеприпасов, перегрев. По сути это ванильная логика под новые классы.
- `mod_net_rpcs` и `mod_ini_keys` пусты: своих RPC и ini-ключей нет.
